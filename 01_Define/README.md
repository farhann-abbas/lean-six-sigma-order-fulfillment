# 01 — Define

## Purpose

The Define phase establishes the business problem, project scope, customer requirement, Critical-to-Quality (CTQ) characteristic, and primary performance measure for the Lean Six Sigma project.

## Project Focus

**Project:** Improving Customer Order Fulfillment Reliability Using Lean Six Sigma DMAIC

The project focuses on customer order fulfillment within an FMCG-style supply chain.

## Primary CTQ

**Customer Order Fulfillment**

The primary CTQ selected for the project is customer quantity fulfillment.

## Primary Y

**Customer Quantity Fill Rate**

Customer Quantity Fill Rate is initially defined as:

> Total Shipped Quantity ÷ Total Ordered Quantity × 100

The measurement definition and treatment of cancelled orders are further documented in the Measure phase.

## Process Boundary

The project process boundary is:

> Customer Order Created → Order Processing → Inventory Availability Check → Allocation → Replenishment if Required → Picking/Fulfillment → Shipment → Customer Order Fulfilled/Unfulfilled

## Scope

### In Scope

- Customer sales-order fulfillment
- Ordered versus shipped quantities
- Product and category fulfillment
- Warehouse-level fulfillment analysis
- Inventory availability
- Reorder-point status
- Supplier performance
- Purchase-order fulfillment
- Statistical analysis of fulfillment variation
- Improvement recommendations
- Control planning

### Out of Scope

- Pricing
- Marketing
- Financial accounting
- Transportation-network optimization beyond available data
- Workforce optimization where supporting data is unavailable
- Changes to actual company operations

## Evidence Boundary

The dataset does not contain direct customer interviews, surveys, complaints, or VOC transcripts. VOC and CTQ documentation therefore uses the available operational data and project context rather than direct customer interview evidence.

The dataset is synthetic and is used for portfolio and analytical demonstration purposes.
